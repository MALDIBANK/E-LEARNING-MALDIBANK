# Welcome to the MALDIBANK E-Learning Course

![MALDIBANK logo](assets/images/logo.png){ width="320" }

The **MALDIBANK** project aims to create a global, cloud-based, open-access platform for microbial MALDI-TOF MS spectra, improving the identification of microorganisms.

Learn more about the project at [maldibank.eu](https://maldibank.eu/).

## Course modules


To start the e-learning, see the button at the bottom right of this page.
1. Introduction, Safety & Materials
2. Sample Prep — Yeast & Filamentous Fungi
3. Sample Prep — Bacteria
4. Preparing the MALDI-TOF Target Plate
5. Cleaning Reusable Target Plates

Please complete all five modules in order.
